# Template - Mini-BD Marketing / Acquisition

## Objectif
Mini-BD de 8-12 pages qui raconte un probleme client, montre la transformation
et convertit vers une offre.
Format ideal pour lead magnet, contenu LinkedIn, support de vente visuel.
Ideal pour 99school : attirer des artisans, associations, TPE vers les ateliers IA.

## Structure (10 pages)

| Page | Acte | Contenu |
|------|------|---------|
| 1 | Couverture | Titre accrocheur, personnage representatif, promesse |
| 2 | Personnage | Presentation du heros (client ideal) et sa situation |
| 3 | Probleme 1 | La frustration principale, clairement montree |
| 4 | Probleme 2 | Aggravation, tentatives ratees |
| 5 | Decllic | Moment ou tout change (decouverte, rencontre) |
| 6 | Solution | Introduction de la methode / solution |
| 7 | Transformation 1 | Premier changement visible |
| 8 | Transformation 2 | Resultat concret, avant/apres |
| 9 | Resultat final | Situation ideale atteinte |
| 10 | CTA | Appel a l'action doux + coordonnees |

## Personnages
- Protagoniste = client ideal (meme age, meme probleme que la cible)
- Personnage de solution = formateur, outil, mentor (optionnel)
- Coherence des personnages OBLIGATOIRE sur toutes les pages

## Regles de design BD
- Cases manga/BD classiques avec goutieres
- Bulles de dialogue bien lisibles
- Expressions de visages expressives
- Texte court dans les bulles (max 15 mots par bulle)
- MODELE IMAGE OBLIGATOIRE : GPT Image 2

## Couleurs 99school
- Orange (#FCA311), Noir (#111111), Blanc (#FFFFFF)

## Dimensions
- Portrait : 1600x2560 px ou 1800x2700 px

## Style anchor type
"Page [N]/10 d'une mini-BD marketing style [STYLE BD],
dimensions [WxH]px,
[description du personnage principal pour coherence],
palette [COULEURS], bulles de dialogue blanches avec contour noir,
texte en francais dans les bulles, tres lisible,
mise en page a [N] cases par page,
tout le texte est rendu dans l'image par GPT Image 2"

## Prompt exemple - page probleme
"[STYLE ANCHOR] Page [N]/10, scene : [NOM] est [SITUATION FRUSTRANTE],
MISE EN PAGE : 3 cases horizontales,
Case 1 : [description de la scene - lieu, personnage, action]
  Bulle dialogue : '[TEXTE MAX 12 MOTS]'
Case 2 : [suite de la scene, frustration visible sur le visage]
  Bulle dialogue : '[TEXTE]'
  Bulle pensee : '[PENSEE INTERIEURE]'
Case 3 : [moment de blocage ou d'echec]
  Narration : '[TEXTE DE NARRATION]',
personnage [NOM] : [description complete pour coherence],
tout le texte en francais rendu dans l'image par GPT Image 2"

## Prompt exemple - page CTA

  '[CTA EN 5 MOTS MAX]'
  '[NOM / MARQUE]'
  '[CONTACT / LIEN]',
tout en francais, GPT Image 2 obligatoire"
