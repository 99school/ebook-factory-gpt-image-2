# Template - Guide Formation IA (pour non-techniciens)

## Objectif
Guide illustre clair et rassurant pour apprendre a utiliser l'IA,
desine a des TPE, artisans, associations et entrepreneurs sans formation technique.
Ton : pedagogique, chaleureux, motivant, sans jargon.

## Public cible
Entrepreneurs 30-65 ans, non-techniciens.
Centres sociaux, associations, artisans, commercants, QPV.

## Structure (30 pages)

| Page | Type | Contenu |
|------|------|---------|
| 1 | Couverture | Titre, sous-titre, auteur, visuel rassurant |
| 2 | Sommaire | Liste des chapitres avec numeros de page |
| 3 | Introduction | Pourquoi l'IA peut vous aider (sans peur) |
| 4 | Chapitre 1 titre | Page de separation visuelle |
| 5-8 | Contenu ch.1 | Concept 1 : definition + cas pratique + icone |
| 9 | Chapitre 2 titre | Page de separation |
| 10-13 | Contenu ch.2 | Outil / action / avant-apres |
| 14 | Chapitre 3 titre | Page de separation |
| 15-18 | Contenu ch.3 | Etapes illustrees |
| 19 | Chapitre 4 titre | Page de separation |
| 20-23 | Contenu ch.4 | Erreurs a eviter |
| 24 | Recap visuel | Infographie synthese |
| 25 | Plan d'action | Mes 3 premieres actions |
| 26 | CTA | Invitation a passer a l'action |
| 27 | Ressources | Outils recommandes |
| 28 | A propos | Bio auteur + contacts |

## Chapitres types
1. Qu'est-ce que l'IA vraiment ? (demystifier)
2. Les 3 outils IA a connaitre absolument
3. Creer votre premier contenu IA en 15 minutes
4. Les erreurs classiques et comment les eviter

## Style
- Moderne et accessible, illustrations simples et expressives
- Pictogrammes / icones pour chaque concept
- Peu de texte par page (max 50-60 mots visibles)
- Grands titres tres lisibles
- Encadres colores pour les points cles
- Couleurs chaudes et rassurantes
- MODELE IMAGE OBLIGATOIRE : GPT Image 2

## Couleurs 99school
- Orange (#FCA311), Noir (#111111), Blanc (#FFFFFF)

## Dimensions
- Format portrait : 1600x2560 px (KDP ebook) ou 1800x2700 px (print 6x9")
